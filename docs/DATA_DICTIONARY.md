# Data Dictionary

The definitions below match `sql/schema.sql`.

## BRANCH

| Column | Data type | Key | Constraints | Description |
|---|---|---|---|---|
| BranchID | INT AUTO_INCREMENT | PK | Generated | Unique branch identifier. |
| BranchName | VARCHAR(100) | | NOT NULL | Human-readable branch name. |
| IFSCCode | CHAR(11) | UK | NOT NULL, `^[A-Z]{4}0[0-9]{6}$` | Indian IFSC code; unique. |
| Address | VARCHAR(255) | | NOT NULL | Branch address. |
| City | VARCHAR(80) | | NOT NULL | Branch city. |
| State | VARCHAR(80) | | NOT NULL | Branch state. |
| ContactNumber | VARCHAR(15) | | NOT NULL, `^[0-9]{10,15}$` | Branch phone. |

## CUSTOMER

| Column | Data type | Key | Constraints | Description |

| LastName | VARCHAR(60) | | NOT NULL | Family name. |

| Address | VARCHAR(255) | | NOT NULL | Residential address. |
| City | VARCHAR(80) | | NOT NULL | Customer city. |
| RegistrationDate | DATETIME | | NOT NULL, DEFAULT CURRENT_TIMESTAMP | When the customer was registered. |

## ACCOUNT

| Column | Data type | Key | Constraints | Description |
|---|---|---|---|---|
| AccountID | INT AUTO_INCREMENT | PK | Generated | Internal account identifier. |
| AccountNumber | VARCHAR(12) | UK | NOT NULL, exactly 12 digits | Customer-facing account number, generated by the app. |
| AccountType | ENUM('Saving','Current','Salary') | | NOT NULL | Type of account. |
| OpeningDate | DATETIME | | NOT NULL, DEFAULT CURRENT_TIMESTAMP | Account opening time. |
| Balance | DECIMAL(15,2) | | NOT NULL, DEFAULT 0.00, >= 0 | Current monetary balance. |
| Status | ENUM('Active','Inactive','Closed') | | NOT NULL, DEFAULT 'Active' | Operational state. Closed cannot be reopened. |
| BranchID | INT | FK -> BRANCH | NOT NULL | Owning branch. |

## ACCOUNT_HOLDER

| Column | Data type | Key | Constraints | Description |
|---|---|---|---|---|
| CustomerID | INT | PK, FK -> CUSTOMER | NOT NULL | Customer linked to the account. |
| AccountID | INT | PK, FK -> ACCOUNT | NOT NULL | Account linked to the customer. |
| HolderSince | DATETIME | | NOT NULL, DEFAULT CURRENT_TIMESTAMP | Start of holder relationship. |
| HolderType | ENUM('Primary','Joint') | | NOT NULL, DEFAULT 'Primary' | Holder role. Trigger enforces one Primary per account. |

Composite primary key: `(CustomerID, AccountID)`.

## BANK_TRANSACTION (logical entity: TRANSACTION)

| Column | Data type | Key | Constraints | Description |
|---|---|---|---|---|
| TransactionID | BIGINT AUTO_INCREMENT | PK | Generated | Unique transaction identifier. |
| AccountID | INT | FK -> ACCOUNT | NOT NULL | Account affected. |
| TransactionType | ENUM('DEPOSIT','WITHDRAWAL','TRANSFER_IN','TRANSFER_OUT') | | NOT NULL | Movement type. |
| Amount | DECIMAL(15,2) | | NOT NULL, > 0 | Transaction value. |
| TransactionDate | DATETIME | | NOT NULL, DEFAULT CURRENT_TIMESTAMP | When the movement occurred. |
| Description | VARCHAR(255) | | NULL | Optional note. |
| ReferenceNumber | VARCHAR(60) | UK | NULL | Unique reference for the individual transaction row. |
| TransferGroupReference | VARCHAR(50) | Indexed | NULL; required for transfer types, absent for deposit/withdrawal | Shared identifier linking the two sides of a transfer. |
| TransactionStatus | ENUM('SUCCESS','FAILED','PENDING') | | NOT NULL, DEFAULT 'SUCCESS' | Result of the movement. |

Named check `chk_transaction_transfer_reference` enforces the transfer-reference rule. Triggers prevent UPDATE and DELETE, preserving history.

## LOAN

| Column | Data type | Key | Constraints | Description |
|---|---|---|---|---|
| LoanID | INT AUTO_INCREMENT | PK | Generated | Unique loan identifier. |
| CustomerID | INT | FK -> CUSTOMER | NOT NULL | Borrowing customer. |
| BranchID | INT | FK -> BRANCH | NOT NULL | Processing branch. |
| LoanType | ENUM('Home Loan','Education Loan','Personal Loan','Vehicle Loan') | | NOT NULL | Loan product. |
| LoanAmount | DECIMAL(15,2) | | NOT NULL, > 0 | Sanctioned/requested principal. |
| InterestRate | DECIMAL(5,2) | | NOT NULL, 0-50 | Annual percentage rate. |
| StartDate | DATE | | NOT NULL | Loan start date. |
| TenureMonths | INT | | NOT NULL, 1-600 | Loan duration in months. |
| LoanStatus | ENUM('Pending','Approved','Rejected','Closed') | | NOT NULL, DEFAULT 'Pending' | Workflow state. |

Outstanding balance is not stored. It is derived as `LoanAmount - SUM(LOAN_PAYMENT.Amount)`.

## LOAN_PAYMENT

| Column | Data type | Key | Constraints | Description |
|---|---|---|---|---|
| PaymentID | INT AUTO_INCREMENT | PK | Generated | Unique payment identifier. |
| LoanID | INT | FK -> LOAN | NOT NULL | Loan receiving the payment. |
| PaymentDate | DATETIME | | NOT NULL, DEFAULT CURRENT_TIMESTAMP | Payment time. |
| Amount | DECIMAL(15,2) | | NOT NULL, > 0 | Amount paid. |
| PaymentMode | ENUM('Cash','Cheque','NEFT','UPI','Card') | | NOT NULL | Payment channel. |
| ReferenceNumber | VARCHAR(60) | UK | NULL | Unique payment reference. |

The `trg_loan_payment_before_insert` trigger rejects payments for non-approved loans and overpayments. `trg_loan_payment_after_insert` closes the loan when fully paid.
